# DEVFLOW-WORKSPACE

DevFlow is a next-generation, browser-based web IDE and developer workspace designed for seamless frontend prototyping. It combines a lightning-fast code editor, real-time live preview for static websites (`index.html`, `style.css`, `script.js`), and an integrated AI assistant into a single, high-performance web application.

* Live At: []

# Key Features

*  Landing Page & Workspace Toggle:** Features a high-tech modern landing page complete with glowing aesthetics, interactive feature cards,  and a smooth animated text marquee.
*  Multi-File Workspace Explorer:** Manage project files efficiently with a clean sidebar file explorer supporting custom file structures.
*  Real-Time Live Preview Sandbox:** Instantly see your HTML, CSS, and JavaScript changes render live in a secure sandbox without manual page refreshing.
*  AI Code Partner:** An integrated AI assistant panel ready to help debug, refactor, and write code on the fly.
*  Customizable Settings:** Easily switch between dark/light themes and toggle AI personas based on your workflow.


# Tech Stack

*  Frontend:** React, TypeScript, Vite
*  Styling:** Tailwind CSS
*  Icons:** Lucide React
*  Deployment:** Vercel
